# adminwork

Admin and operations repo for [Camp Spin Off](https://campspinoff.com) — the only overnight residential DJ camp for teens in the US.

## Weekly Sponsor Outreach

Every Monday, a new sponsor research file is added to `sponsors/` with fresh prospects to reach out to. A draft email is also created in Gmail at tina@campspinoff.com.

### How it works

1. Claude researches new potential sponsors and partners aligned with Camp Spin Off's mission
2. A markdown file is saved to `sponsors/YYYY-MM-DD.md` (dated for that Monday)
3. A formatted HTML draft email is created in Gmail for easy review and send
